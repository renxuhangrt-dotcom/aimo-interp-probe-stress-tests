## 接下来四个工作包

### A. 报告与证据（优先级最高）

- 校对技术报告中的每一个数字，使其都能追溯到冻结 JSON。
- 把公开实现整理成最小可复现实验包，删除下载缓存、模型权重和任何密钥。
- 在官方发布最终报告格式后，将当前主稿压缩到要求页数；竞赛提案写的是
  1–2 页，当前官网只要求技术报告，因此先保留较完整主稿。

### B. 公开实现

- 建立一个干净仓库，仅包含数据准备、Kaggle 提取、训练、门槛、打包、回放、
  E10 审计和图表生成脚本。
- README 提供从官方数据到所有表格的一键顺序，所有外部输入带版本和哈希。
- 发布前进行许可证、隐私、压缩包和凭证扫描。

### C. 新验证来源

- 关注组织方是否发布新的标注验证集或报告提交模板。
- 询问组织方能否提供一次不反馈单题信息的独立验证，或允许将某种不同
  扰动类型作为开发标签。
- 在来源、规则、样本量和哈希未确定前，不启动 V8。

### D. 新假设储备

- 只保留“扰动响应几何”作为候选：比较同一道题多个无标签、保义变体的
  内部表示或置信轨迹稳定性。
- 不再尝试现有单提示 hidden state 上的换层、换阈值、换分类器或换 pooling。
- 候选方法必须先通过 `NEW_MODEL_GATE.md` 的七项审查。

## 每周 20 小时建议分配

- 8 小时：报告正文、图表和引用校对。
- 5 小时：开源复现包与自动测试。
- 4 小时：寻找并核实独立验证来源及比赛规则更新。
- 3 小时：只做新假设的理论设计和预注册，不接触冻结测试标签。
